# PLC Toolkit

Console toolkit for **Allen-Bradley / Rockwell Automation** PLCs: tag discovery, export (Excel, JSON, XML), live reads, and monitoring over EtherNet/IP.

## Run from source

- Python 3.8 or later  
- Dependencies: `pycomm3`, `openpyxl`  
- Main entry point: `plc_toolkit_consolidated.py`

## Windows executable

See `PACKAGING_GUIDE.md`, or on a Windows machine with Python on your PATH run `BUILD_WINDOWS_EXE.bat` or `python make_exe.py`. Output is `PLC_Toolkit.exe` plus `Run_Toolkit.bat`.
