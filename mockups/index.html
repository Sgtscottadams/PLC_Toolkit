PLC Toolkit — Wireframe Set

Honest wireframes (boxes & labels, no real styling). These are intended to verify navigation and layout only, not visual polish. Click any screen below to view it.

All wireframes are static HTML; no JavaScript is executed. Anchor width: 1280px.

Screens

  • 01 — Connection Manager | Root screen, always shown on launch. Lists saved PLCs.
  • 02 — New Connection (modal) | Modal dialog: nickname, IP, slot, CIP path.
  • 03 — Discover PLCs (modal) | Subnet discovery with probe list and results table.
  • 04 — Workspace: Browse | Connected state. Tag tree on the left, detail pane on the right.
  • 05 — Workspace: Monitor | Watch list with current values and sparkline placeholders.
  • 06 — Workspace: Export | Source selection, format checkboxes, output folder, filename.
  • 07 — Workspace: History | Past scans for the connected PLC, with per-row actions.
  • 08 — Workspace: Diagnostics | Connection summary, bandwidth, recent activity log.
  • 09 — Settings (modal) | All app-level preferences grouped by section.
  • 10 — Help (placeholder) | Intentionally not implemented. Flagged for v2.1.

Navigation Tree

Click-flow from launch. Asterisk marks the screen you reach; number is "clicks from launch".

  • Launch → app opens to
    • 01 Connection Manager [0 clicks from launch]
    • From Connection Manager, the user can go to:
      • 02 New Connection (modal) [+1 click: "+ Connect to a new PLC" → 1 click from launch]
      • 03 Discover PLCs (modal) [+1 click: "Discover" link/button → 1 click from launch]
      • 09 Settings (modal) [+1 click: gear icon → 1 click from launch]
      • 10 Help [+1 click: ? icon → 1 click from launch]
      • 04 Workspace: Browse [+1 click: "Connect" on a row → 1 click from launch]
        • From inside the workspace, tabs swap without leaving the screen:
          • 05 Monitor [2 clicks from launch]
          • 06 Export [2 clicks from launch]
          • 07 History [2 clicks from launch]
          • 08 Diagnostics [2 clicks from launch]

Notes for the reviewer

  • All wireframes share wireframe.css. No colors, no shadows, no rounded corners beyond 4px.
  • Each screen has a "X click(s) from launch" badge in the top right of its top bar.
  • Ambiguities in the spec are flagged inline with a dashed grey note that begins [DRAFT:.
  • The "New Connection" and "Discover PLCs" screens are drawn as modal dialogs over a dimmed view of the Connection Manager.
  • The Help screen is intentionally a stub.
